MATERIAL DESK - PORTABLE OFFLINE DASHBOARD

1. Extract the ZIP to any folder.
2. Double-click Material Desk.html to open it in a modern browser.

No installation, account, API key, server, Node.js, Python or internet is required for the charts. The HTML contains the dashboard, chart library, styles and all three series. It can also be shared on its own. Fonts use built-in system fonts.

DATA SNAPSHOT
Downloaded November 10, 2026 (America/Chicago); latest observation September 2026. Source: US Bureau of Labor Statistics via FRED. Monthly, not seasonally adjusted, 1982=100. Raw CSVs are included for reference. Editing the CSVs does not change the embedded data: use Import FRED CSV.

USING THE DASHBOARD
Choose a material and chart view. New view copies the current dates and chart selection. Each view retains separate dates and zoom. Tabs scroll above ten views (earlier on small screens). Close with x; Undo close restores the last closed view. Closing the last view creates a default. Focus a tab and use Left/Right, Home/End or Delete. Scroll/pinch to zoom, drag to pan, or use the slider. PNG export: select charts and settings, Prepare selected PNGs, then use each download link.

UPDATING AND SHARING DATA
While online, download CSVs from FRED via the links in Import FRED CSV. Select one or more files; the header identifies the material. Files are validated before updates are applied. CSV import is local; it uploads nothing.
Save portable HTML downloads a new self-contained file containing currently loaded data. Share that HTML or put it in a ZIP. No live refresh is required or performed.

View settings and imported CSVs are saved in this browser when local-file storage is supported. Moving/renaming the file or using another browser may create separate storage. Save portable HTML reliably keeps imported data in a distributable copy. Saved browser imports take precedence when reopening; a new recipient sees the embedded snapshot. View layouts are local preferences, not embedded in saved copies.

SOURCES AND METHODS
https://fred.stlouisfed.org/series/WPU08 - Lumber and wood
https://fred.stlouisfed.org/series/WPU101 - Iron and steel
https://fred.stlouisfed.org/series/WPU133 - Concrete products
Month-over-month = 100 * (index / previous calendar month's index - 1).
Year-over-year uses the same month one year earlier.
Volatility = sample standard deviation of 12 consecutive monthly percentage changes; percentage points, not annualized.
Full-history lookbacks precede filtering. Missing months remain gaps; no interpolation. Indices are not quotes or local installed costs. Data may be revised.

The key, project notes and brief are session-only and never included in browser storage, Save portable HTML or the ZIP. Forget key & clear brief clears the session; closing the dialog cancels a pending request. Download brief as text explicitly exports the result. Errors do not disable the charts.
